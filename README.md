# South Korea Itinerary Planner

A responsive, static itinerary planner for 26 October–4 November 2026. Open `index.html` in a modern browser. No build step or dependencies are required.

## Project structure

- `index.html` — page structure and content shell
- `assets/css/styles.css` — layout, responsive styles, and visual theme
- `assets/js/itinerary-data.js` — itinerary dates, activities, notes, and map-search place names
- `assets/js/app.js` — rendering, accordion controls, search, editable price totals, checklist export, and Google Maps links

## Features

- All day panels start **collapsed**.
- Expand/collapse all, search, per-stop Google Maps links, and day route links.
- Editable KRW price fields and per-day totals.
- Export a plain-text checklist.

Times and prices are planning placeholders, not confirmed bookings or live-verified opening hours. Confirm schedules, addresses, and reservations before travel.
